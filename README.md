# NC Decision Program — AI агент Damu по ОКЭД и территории

**NC Decision Program** — профессиональная система интеллектуального подбора и скоринга финансовых мер государственной поддержки АО «Фонд развития предпринимательства «Даму» (АО «ФРП «Даму») для субъектов предпринимательства Республики Казахстан.

Разработано: **NC Consulting**

---

## Ключевые возможности

1. **Точный скоринг по кодам ОКЭД и территории (ТЗ Разделы 3, 5, 8)**
   - Проверка по 20 регионам Казахстана (17 областей + 3 города республиканского значения: Астана, Алматы, Шымкент).
   - Учет исключений городов республиканского значения (например, для программы «Іскер аймақ»).
   - Учет приоритетов моногородов и малых сельских населенных пунктов.
   - Поддержка торговых ОКЭД (разделы 46, 47, а также 68.20.3-68.20.5 для программы «Субсидирование в сфере торговли»).

2. **Официальный реестр программы «Өрлеу»**
   - Полная база приоритетных ОКЭД программы «Өрлеу» (секция C «Обрабатывающая промышленность», транспорт и логистика 49.20.0, 49.41.0, 52.10.1, 52.24.0, 68.20.8).
   - Учет регламентных исключений (ОКЭД 20.15 — удобрения, 23.51 — цемент, 23.63 — товарный бетон, производство алкоголя и табака).

3. **Интерактивная векторная карта регионов и приоритетов МИО (Акиматов)**
   - SVG-карта Казахстана с 20 административно-территориальными единицами.
   - Быстрый фильтр по ОКЭД для выявления регионов со специальными ставками софинансирования (6%–7,5%).
   - Профили региональных программ (Almaty Business, Астана Start, Shymkent Damu и др.).

4. **Экспорт экспертного заключения в DOCX и печать**
   - Формирование официального отчета в формате Microsoft Word (`.docx`) с реквизитами NC Consulting, разбивкой по ОКЭД, территории, лимитам, ставкам и первоисточникам.

5. **Двуязычность и темы оформления**
   - Полная локализация на русский (RU) и казахский (KK) языки.
   - Поддержка фирменной Neon Cyberpunk темы и контрастной Light темы.
